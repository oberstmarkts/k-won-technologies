# 케이원테크 원페이지 사이트

정적 HTML, CSS, JavaScript로 만든 홍보 사이트입니다. 별도 빌드나 외부 스크립트가 필요하지 않습니다.

## 공개 정보 원칙

- 상호와 등록 사업영역은 2026-08-18 사업자등록증의 공개 가능한 항목을 바탕으로 정리했습니다.
- 개인 식별정보, 사업자등록번호, 상세 주소는 사이트에 게시하지 않습니다.
- 기업용 AI, 보안 등은 Notion 사업계획의 **방향**으로만 표시하며, 실적·인증·상용 제품으로 주장하지 않습니다.
- 연락처가 확인되기 전까지 임의 이메일이나 작동하지 않는 문의 양식을 만들지 않습니다.

## 로컬 확인

`python -m http.server 8000` 실행 후 `http://localhost:8000`에 접속합니다.

## GitHub Pages

공개 저장소의 루트에서 `main` 브랜치를 배포 소스로 선택합니다. Pages 설정 권한과 URL 응답을 별도로 확인해야 공개 완료로 판정합니다.
