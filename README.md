정적 HTML, CSS, JavaScript로 만든 사업체별 홍보 사이트입니다. 별도 빌드나 외부 스크립트가 필요하지 않습니다.

| 사업체 | 경로 |

| 케이원테크 | `/` |
| 다담출판 | `/dadam-publishing/` |
| 공유형작업실 | `/shared-studio/` |
| 프로핏팜 | `/pro-fit-farm/` |

## 공개 정보 원칙

- 상호와 등록 사업영역은 `E:/CEO`의 각 사업체 사업영역 정정 PDF에서 공개 가능한 항목을 확인해 정리했습니다. 다담출판은 2026-08-21, 나머지는 2026-08-18 문서입니다.
- 브랜드 방향은 For Founder의 해당 사업체 Notion 페이지와 2026-09-13 홈페이지 리뉴얼 기획안을 참고했습니다. 기획안은 현재 운영 실적의 증거가 아닙니다.
- 개인 식별정보, 사업자등록번호, 상세 주소는 사이트에 게시하지 않습니다.
- AI·자동화·콘텐츠 확장 등은 Notion 사업계획의 **방향**으로만 표시하며, 실적·인증·상용 제품으로 주장하지 않습니다.
- 연락처가 확인되기 전까지 임의 이메일이나 작동하지 않는 문의 양식을 만들지 않습니다.
